По пути C:\\Users\\user\\.ssh создаешь файл config с содержанием примерно: 

Host chestnut

&#x20;   HostName 195.19.213.59

&#x20;   User root

&#x20;   IdentityFile \~/.ssh/mykey





Запускаешь повершелл, пишешь ssh  chestnut

Выполнится конфиг, запустится сервер.

Если ssh ключ был прописан в конфиге сервера просто запустится сервер, если нет, может быть такое
